# Task Plan: task0009 — config/runner/markup robustness

## Goal

Close the remaining robustness gaps in the GTK-free logic packages:
watcher delete/rename notification, config validation (non-positive
interval, duplicate section keys), bounded interval capture, stream
oversized-line handling, and Pango attribute validation.

## Requirements

FR4, FR5, FR6, FR9, NFR2

## Scope

### Files to Create
- None.

### Files to Modify
- `internal/config/watcher.go` — treat target-file Remove/Rename as reload notifications
- `internal/config/watcher_test.go`
- `internal/config/load.go` — reject non-positive intervals; reject duplicate section keys (two sections with identical `Key()`) with a descriptive error
- `internal/config/load_test.go`
- `internal/runner/interval.go` — bound stdout capture (fixed limit, e.g. 1 MiB); on overflow terminate the run and emit an error event noting truncation
- `internal/runner/interval_test.go`
- `internal/runner/stream.go` — check the scanner error after the read loop; on oversized-line (or other read) errors terminate and reap the process and emit an error event instead of waiting for natural exit
- `internal/runner/stream_test.go`
- `internal/markup/markup.go` — validate span attributes against the Pango-supported set so GTK never receives markup Pango rejects; unknown attributes → escaped fallback
- `internal/markup/markup_test.go`

## Design

Review findings addressed (reviews/round1.yaml): 16264b3ee1dc0f76,
1da5aded1a6cc024, e73fc29c7e253aec, 92a5f35f1a3803b6, 2bdf9474e17c2ce9,
79ee90b6791ed8df, 81e6ac3cd113fd5e.

- Watcher: extend the event filter to Remove/Rename on the target file
  name; the resulting failed Load flows through the existing last-good +
  banner path. Editor rename/replace saves must not double-notify
  (debounce already collapses bursts).
- Duplicate keys: with Name part of `Key()` (loop-2 decision), exact
  duplicates are configuration errors — reject at validation with the
  section indices in the message. This also closes the UI widget-leak
  path for duplicates.
- Interval capture: bounded writer; overflow is an error event for that
  section (`error: output exceeded limit ...`), the run is terminated and
  reaped, and the cycle continues at the next tick.
- Stream scanner: after the scan loop, inspect the scanner's error; on
  ErrTooLong or read errors, terminate + reap via the existing graceful
  path and emit an error event.
- Markup: whitelist Pango span attributes (font, font_desc, font_family,
  face, size, style, weight, variant, stretch, foreground/fgcolor/color,
  background/bgcolor, alpha/fgalpha, background_alpha/bgalpha, underline,
  underline_color, overline, overline_color, rise, baseline_shift,
  font_scale, strikethrough, strikethrough_color, fallback, lang,
  letter_spacing, gravity, gravity_hint, font_features, allow_breaks,
  insert_hyphens, line_height, text_transform, segment, show); other
  whitelisted tags take no attributes. Unknown attribute → invalid →
  escaped fallback. Attribute VALUES are not validated (documented
  limitation; value errors are rare and Pango's value parsing is not
  reproducible without GTK).

## Acceptance Criteria (MANDATORY)

- [ ] AC-1: Deleting the watched config file produces a watcher notification (and a rename-away does too); editor rename/replace saves still yield a single debounced notification.
- [ ] AC-2: `interval: 0s` and negative intervals are validation errors; duplicate section keys are validation errors naming the offending sections.
- [ ] AC-3: An interval command exceeding the output limit yields an error event for that section (not unbounded memory), and later runs continue.
- [ ] AC-4: A stream line exceeding the scanner limit terminates and reaps the process and emits an error event — no stranded child, `Stop` returns promptly.
- [ ] AC-5: `<span badattr="x">` (unknown attribute) falls back to escaped plain text; whitelisted attributes still pass through; attribute-free whitelisted tags unchanged.
- [ ] AC-6: `go test ./...` passes headlessly (including -race on the runner package); `gofmt` clean.
