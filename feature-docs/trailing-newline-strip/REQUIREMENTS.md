# 出力末尾改行のストリップ - 要件定義書

## 1. 概要

### 1.1 背景

実機で、セクションの出力テキストと下の横罫線の間に約1行分の空きが観察された。原因は、コマンド stdout の末尾改行がそのまま Pango マークアップとして GtkLabel に渡り、空の最終行が描画されるため。デザイン仕様（process-output-widget/DESIGN.md）は「出力の末尾改行は描画前に全て取り除く。途中の空行は保持」と定めており、実装が追随していない。

### 1.2 目的

DESIGN.md の決定を実装に反映し、出力テキストの直下に罫線・パディングが来る表示にする。

### 1.3 スコープ

- 表示描画経路での末尾改行ストリップ（interval / stream / セクションエラーの全経路）
- 対象外: ring buffer の保持内容の変更、罫線・パディング等のレイアウト定数の変更

## 2. 機能要件

### 2.1 機能一覧

| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F01 | 末尾改行ストリップ（interval） | interval 実行の出力の末尾改行を描画前に全て取り除く | 高 |
| F02 | 末尾改行ストリップ（stream） | stream 表示（バッファ行の結合結果）の末尾空行を表示しない | 高 |
| F03 | 末尾改行ストリップ（エラー表示） | セクションエラーテキストの末尾改行を描画前に取り除く | 中 |
| F04 | 途中空行の保持 | 出力途中の空行は内容としてそのまま表示する | 高 |
| F05 | 空出力の扱い | 改行のみの出力は空表示にする（ラベルのみのセクションになる） | 中 |

### 2.2 機能詳細

#### F01: 末尾改行ストリップ（interval）

**説明**: interval 実行（KindReplace）の stdout を描画する際、末尾の改行を全て取り除く。

#### F02: 末尾改行ストリップ（stream）

**説明**: stream 実行（KindAppend）の表示内容（バッファ行を結合した文字列）の末尾空行を表示しない。ring buffer 自体の保持内容は変更しない。

#### F03: 末尾改行ストリップ（エラー表示）

**説明**: セクションエラー表示（`error: {message}`）のメッセージ末尾の改行も取り除く。

#### F04: 途中空行の保持

**説明**: 出力の途中にある空行は内容として保持し、そのまま表示する。

#### F05: 空出力の扱い

**説明**: 出力が改行のみの場合、ストリップの結果として空文字列を表示する。

## 3. 非機能要件

- 新規外部依存を追加しない
- 品質ゲート: `go build ./...` / `go test ./...` / `gofmt -l -w .` がクリーン

## 4. 制約条件

- デザインの SSOT は feature-docs/process-output-widget/DESIGN.md（Output text の決定）およびモック状態 `trailing-newline`
- レイアウト定数（罫線・パディング）には触れない

## 5. 成功基準

### 5.1 受け入れ基準

- [ ] 末尾改行付きの interval 出力で、テキスト直下に空行が描画されない
- [ ] stream 表示でも末尾空行が表示されない
- [ ] セクションエラー表示の末尾改行が取り除かれる
- [ ] 途中の空行は表示に保持される
- [ ] 改行のみの出力は空表示になる

### 6.1 確認済み事項

- [x] セクションエラー表示にも適用する
