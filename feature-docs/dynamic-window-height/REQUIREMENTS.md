# ウィンドウ高さの動的決定 - 要件定義書

## 1. 概要

### 1.1 背景
現在、ウィンドウの高さは設定ファイルの `window.height`（デフォルト 600）で固定されている。セクション出力の量に対して高さが合わず、余白が出たり表示が切れたりする。

### 1.2 目的
ウィンドウの高さをコンテンツ（セクション出力）から動的に決定し、`window.height` 設定を廃止する。

### 1.3 スコープ
- ウィンドウ高さの決定ロジックの変更
- 設定スキーマからの `window.height` の削除
- `config.yaml.example` からの `height` 行の削除

`window.width` は対象外（現状のまま設定で指定する）。

## 2. 機能要件

### 2.1 機能一覧
| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F01 | 高さの動的決定 | ウィンドウ高さをコンテンツの自然高さから決定する | 高 |
| F02 | コンテンツ変化への追従 | セクション出力の増減に合わせて高さが随時伸縮する | 高 |
| F03 | 高さ上限 | 高さの上限はモニタの高さとし、超えた分は表示が切れる | 高 |
| F04 | height 設定の削除 | 設定スキーマから `window.height` を削除する。YAML に `height` が書かれていても黙って無視する | 高 |

### 2.2 機能詳細

#### F01: 高さの動的決定
ウィンドウの高さは、バナーと全セクションを含むコンテンツの自然高さから決定する。`window.height` による指定は行わない。

#### F02: コンテンツ変化への追従
セクション出力の増減・設定リロードによるセクション構成の変化に合わせて、ウィンドウ高さが随時伸縮する。

#### F03: 高さ上限
コンテンツの自然高さがモニタの高さを超える場合、ウィンドウ高さはモニタの高さを上限とし、超えた分は表示が切れる。

#### F04: height 設定の削除
- 設定スキーマから `window.height` を削除する
- 既存の config.yaml に `height` が書かれていても、エラー・警告を出さず黙って無視する
- `config.yaml.example` から `height` 行を削除する

## 3. 既存挙動の維持

- セクションが 0 個のとき、ウィンドウが掴めるように最小高さ（現状 48px）を維持する
- `window.width` の挙動は変更しない

## 4. 非機能要件

- config パッケージは GTK 非依存を維持し、`go test ./...` でテスト可能であること

## 5. 成功基準

### 5.1 受け入れ基準
- [ ] ウィンドウ高さがコンテンツに合わせて決まる
- [ ] セクション出力の増減で高さが随時伸縮する
- [ ] コンテンツがモニタの高さを超える場合、モニタの高さで頭打ちになる
- [ ] config.yaml に `height` が書かれていてもエラー・警告なしに無視される
- [ ] `config.yaml.example` に `height` 行がない
- [ ] セクション 0 個でも最小高さのウィンドウが表示される
