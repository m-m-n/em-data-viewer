# Task Plan: task0001 — Rename application ID and .desktop filename

## Goal

The app's GTK application ID and the shipped .desktop basename both become
`io.github.m_m_n.EmDataViewer`, making Wayland dock icon resolution match;
everything else (icon names, .desktop content) stays identical.

## Requirements

FR1, FR2, NFR1, NFR2

## Scope

### Files to Create
- (none)

### Files to Modify
- `internal/ui/ui.go` — applicationID constant value + its comment
- `Makefile` — .desktop output filename in the dpkg target

## Design

- `internal/ui/ui.go`: set the applicationID constant to exactly
  `io.github.m_m_n.EmDataViewer` (IMPLEMENTATION.md Shared Components).
  Rewrite the constant's comment: the ID is the Wayland app_id and MUST
  equal the shipped .desktop basename for GNOME Shell icon resolution
  (it is no longer an arbitrary placeholder).
- `Makefile` (dpkg target): the desktop entry is written to
  `usr/share/applications/io.github.m_m_n.EmDataViewer.desktop` (mode 644
  as today). Every content line — including `Icon=em-data-viewer` and
  `StartupWMClass=em-data-viewer` — stays byte-identical; only the
  filename changes. No other target changes.
- Do not touch: hicolor file names, `assets/icon.gresource.xml`,
  `internal/ui/resources.go`, `windowIconName` (SPEC NFR1).

## Acceptance Criteria (MANDATORY)

- [ ] AC-1: the applicationID constant equals
      `io.github.m_m_n.EmDataViewer` and no source file still contains
      `org.dataviewer.Widget`.
- [ ] AC-2: `make dpkg` deb contains
      `usr/share/applications/io.github.m_m_n.EmDataViewer.desktop`
      (mode 644) and contains NO `em-data-viewer.desktop`.
- [ ] AC-3: the shipped .desktop content is byte-identical to the previous
      content (all nine lines, same order, including Icon= and
      StartupWMClass=).
- [ ] AC-4: `make build` and `make test` pass; grep confirms the icon-name
      string usages (hicolor cp targets, gresource XML, windowIconName)
      are unchanged.

## Test Notes

- Rename-only change: verify via shell-level checks (grep, dpkg-deb -c /
  -x, diff of the generated .desktop against the expected nine lines).
- No new Go test expected; existing `make test` guards compilation.
- The GApplication ID validity is static (4 elements, valid chars) — no
  runtime validation code needed.

## Out of Scope

- Any icon-name change (em-data-viewer stays everywhere).
- Renaming the binary, package name, or gresource paths.
- postinst/postrm changes.
