# セクション強制改行オブジェクト - 要件定義書

## 1. 概要

### 1.1 背景
セクションは幅ベースの貪欲な行詰め（section-row-packing / section-flow-layout）で
自動的に折り返されるが、任意の位置で行を確実に切る手段がない。

### 1.2 目的
config の sections 配列に「強制改行オブジェクト」を書けるようにし、
その位置で必ず次の行に折り返す。

```
a │ b          ← break により行が終わる
─────────
c │ d │ e │ f  ← ここからは幅による通常の折り返し
─────────
g │ hij
```

### 1.3 スコープ
- config スキーマ（`- type: break` 要素）の追加とバリデーション
- 行詰めロジックへの強制改行位置の反映
- 対象外: 新しい見た目の追加（区切り線・行間の描画は既存のまま）

## 2. ユースケース

### UC01: 任意位置での強制改行

**アクター**: config を編集するユーザー

**基本フロー**:
1. ユーザーが sections 配列の任意の位置に `- type: break` を挿入する
2. 表示上、break の直前のセクションで行が終わり、直後のセクションは次の行の先頭になる
3. break で区切られた各区間の内部では、従来どおり幅ベースの折り返しが行われる

## 3. 機能要件

### 3.1 機能一覧
| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F01 | break 要素の config 記法 | sections 配列に `- type: break` を書ける | 高 |
| F02 | 強制改行の反映 | break 位置で行詰めを打ち切り次の行へ | 高 |
| F03 | 既存描画の維持 | 区切り線（縦線・横線）は既存ルールのまま | 高 |

### 3.2 機能詳細

#### F01: break 要素の config 記法

**記法**:
```yaml
sections:
  - name: a
    command: "..."
    mode: interval
    interval: 1s
  - type: break
  - name: c
    command: "..."
    mode: interval
    interval: 1s
```

**バリデーション**:
| 項目 | ルール |
|------|--------|
| type | 省略時は通常セクション。`break` は改行オブジェクト。それ以外の値はエラー |
| break 要素のその他フィールド | 無視する（設定ミスはユーザーの責務） |

#### F02: 強制改行の反映

- break で区切られた各区間ごとに、既存の幅ベース行詰めを行う
- 連続した break・先頭や末尾の break は空の区間となり、行を作らない
  （空行や余分な区切り線は生じない）
- break は表示制御のみ: コマンド実行・プロセス管理・再水和（rehydration）の
  対象にならない

#### F03: 既存描画の維持

- break で切られた行境界にも、通常の折り返しと同じ横線（hdivider）を表示する
- 行内の縦線（vdivider）・行間の描画ルールは変更しない

## 4. 非機能要件

- 新規外部依存を追加しない
- `go build ./...`、`go test ./...`、gofmt が全て通る
- ロジックは GUI 非依存のまま（gotk4 を import しないパッケージでテスト可能に保つ）

## 5. 制約条件

- config の書き戻し（`UpdateKeepAbove`）は yaml.v3 の node レベル編集のため、
  break 要素はラウンドトリップで保持される（変更不要）

## 6. 成功基準

- [ ] `- type: break` を含む config が正常に読み込まれる
- [ ] break の位置で必ず行が変わる
- [ ] break 前後の区間内は従来どおり幅で折り返す
- [ ] 連続・先頭・末尾の break が空行を作らない
- [ ] break 由来の行境界にも横線が表示される
- [ ] `type` に不明な値を書くと config エラーになる（last-good 動作は既存どおり）

## 7. 確認事項

### 7.1 確認済み事項
