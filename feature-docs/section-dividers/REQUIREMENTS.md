# セクション区切り罫線 - 要件定義書

## 1. 概要

### 1.1 背景
実機確認で、余白のみのセクション区切りでは縦方向に余分な空間が残り、横方向の境界も不明瞭だった。デザイン更新（design-system/tokens.yaml の `color.divider` / `border.divider-width` 追加、process-output-widget の DESIGN.md・mockup 更新）で、区切りを罫線方式に変更することが確定した。

### 1.2 目的
確定済みのデザイン（罫線によるセクション区切り）を実装に反映する。

### 1.3 スコープ
- 行間の区切り: 余白 → 横罫線（追加余白 0）
- 同一行内のセクション間の区切り: 余白のみ → 縦罫線（左右 1 unit ずつ）
- 罫線の端は 1 unit ずつ浮かせ、外周枠にも他の罫線にも接しない
- 設定エラーバナーとセクションの間に 1 unit の余白を追加
- セクション内部の構造（ラベル+出力）、行詰めアルゴリズム自体は変更しない

## 2. 機能要件

### 2.1 機能一覧
| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F01 | 横罫線 | 行と行の間に 1px の横罫線。縦の追加余白 0、左右端 1 unit 内側 | 高 |
| F02 | 縦罫線 | 同一行内のセクション間に 1px の縦罫線。左右 1 unit ずつ、上下端 1 unit 内側 | 高 |
| F03 | 罫線の非接触 | 罫線同士・外周枠と接しない（角・T 字・十字を作らない） | 高 |
| F04 | 行詰め幅計算の整合 | 行詰め計算の間隔を罫線込みの実占有幅（1 unit + 1px + 1 unit）に合わせる | 高 |
| F05 | バナー下余白 | 設定エラーバナーとセクションの間に 1 unit の余白 | 中 |
| F06 | 既存動作の維持 | config リロード・個別更新・セクション別スタイル・エラー表示・空状態は現状のまま | 高 |

### 2.2 機能詳細

#### F01: 横罫線
- 色 `color.divider` (#666666)、太さ `border.divider-width` (1px)
- 行間の縦距離は罫線のみ（追加余白 0）
- 左右端は 1 unit (6px) 内側に浮かせる

#### F02: 縦罫線
- 色・太さは F01 と同じ
- 罫線の左右に 1 unit ずつの余白
- 罫線の高さは行の高さに追従し、上下端は 1 unit 内側に浮かせる

#### F03: 罫線の非接触
- 行が 1 行だけなら横罫線なし、行内が 1 セクションだけなら縦罫線なし
- セクションが 0 個なら罫線は一切出ない

## 3. 非機能要件

- 罫線の色・太さは固定値（config でのオーバーライド不可）
- 新規外部依存を追加しない
- `go build ./...`、`go test ./...`、gofmt が通ること

## 4. 制約条件

- GUI の見た目の最終確認は手動（自動 E2E なし）
- デザインの SSOT は design-system/tokens.yaml と feature-docs/process-output-widget/DESIGN.md・mockup（更新済み）

### 5.1 受け入れ基準

- [ ] 同一行内のセクションが縦罫線で区切られる
- [ ] 罫線が外周枠・他の罫線と接しない
- [ ] 設定エラーバナーとセクションの間に 1 unit の余白がある
- [ ] config リロード・セクション更新・エラー表示・空状態が従来どおり動作する
