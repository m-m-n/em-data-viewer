# 出力テキストデフォルトフォントサイズ 11pt 化 - 要件定義書

## 1. 概要

### 1.1 背景
セクションの出力テキスト（コマンド出力、monospace）のデフォルトフォントサイズは現在 12pt になっている。

### 1.2 目的
出力テキストのデフォルトフォントサイズを 11pt にする。

### 1.3 スコープ
- 出力テキスト（output-size）のデフォルト値の変更のみ
- ラベル（label-size: 9pt）は変更しない
- config による上書き機構（style.font / output-size）は変更しない

## 2. ビジネス要件

### 2.1 ビジネス目標
該当なし（個人利用ウィジェットの表示調整）

### 2.2 対象ユーザー
| ユーザータイプ | 説明 |
|----------------|------|
| ウィジェット利用者 | data-viewer を常駐表示して使う本人 |

### 2.3 期待される効果
- 出力テキストが 11pt で表示される

## 3. ユースケース

### 3.1 ユースケース一覧
| ID | ユースケース名 | アクター | 優先度 |
|----|----------------|----------|--------|
| UC01 | フォント未指定のセクションを表示する | ウィジェット利用者 | 高 |

### 3.2 ユースケース詳細

#### UC01: フォント未指定のセクションを表示する

**アクター**: ウィジェット利用者

**事前条件**:
- config.yaml のセクションに style.font / output-size の指定がない

**基本フロー**:
1. data-viewer を起動する
2. セクションの出力テキストが 11pt で表示される

**代替フロー**:
- config で style.font（例: "monospace 12"）や output-size を指定している場合は従来どおり指定値が優先される

**事後条件**:
- 出力テキストのデフォルトサイズが 11pt になっている

## 4. 機能要件

### 4.1 機能一覧
| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F01 | output-size デフォルト値変更 | SectionStyleDefaults の output-size を 12pt から 11pt に変更する | 高 |
| F02 | デザイントークン同期 | design-system/tokens.yaml の出力フォントトークンの size を 11pt に更新する | 高 |

### 4.2 機能詳細

#### F01: output-size デフォルト値変更

**説明**: `internal/ui/style.go` の `SectionStyleDefaults["output-size"]` を `"12pt"` から `"11pt"` に変更する。

**入力**: なし（定数値の変更）

**出力**: 生成される CSS の `font-size` が 11pt になる

**ビジネスルール**:
- config による上書き（style.font / output-size）は従来どおり優先される

#### F02: デザイントークン同期

**説明**: `design-system/tokens.yaml` の出力フォントトークン（family: monospace のエントリ）の size を `12pt` から `11pt` に更新し、コードとトークンの SSOT を一致させる。
