# セクションのフローレイアウト - 要件定義書

## 1. 概要

### 1.1 背景
現在、セクションはウィンドウ内に縦一列に積まれる。ウィンドウ幅を広げても各セクションは 1 行を占有したままで、横方向の余白が活用されない。

### 1.2 目的
幅に余裕がある場合にセクションを横に並べ、入りきらない分を次の行に折り返すレイアウトにする。

### 1.3 スコープ
- セクション一覧コンテナのレイアウト変更(縦一列 → 横詰め折り返し)
- セクション内部の構造(ラベル+出力)、セクションの内容・更新機構は変更しない

## 2. 機能要件

### 2.1 機能一覧
| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F01 | 横詰め折り返しレイアウト | セクションを左から右へ並べ、幅が足りなければ次の行へ折り返す | 高 |
| F02 | 自然な幅のセル | 各セクションは内容に必要な幅だけを使う(全セル同幅にしない) | 高 |
| F03 | セクション間隔 | 横 12px(2 unit)、行間 0 | 高 |
| F04 | 装飾なし | コンテナ由来の選択ハイライト・パディングを付けない | 高 |
| F05 | 既存動作の維持 | config リロードによるセクション再構築・個別更新・セクション別スタイル・エラー表示は現状のまま動作する | 高 |

### 2.2 機能詳細

#### F01: 横詰め折り返しレイアウト
- セクションは config の記述順に左から右へ配置される
- 行の残り幅に次のセクションが入らない場合、次の行の先頭に配置される
- 縦一列レイアウトへ戻す設定は設けない(常時このレイアウト)

#### F02: 自然な幅のセル
- 各セクションの幅は自身の内容(ラベル・出力)の自然幅
- 1 行に収まらない幅のセクションは 1 行を占有する(出力の折り返し挙動は現状のまま)

#### F03: セクション間隔
- 同一行内のセクション間: 12px(spacing 2 unit)
- 行間: 0
- design-system のトークン記述もこれに合わせて更新する

#### F04: 装飾なし
- 選択・ホバーによる視覚変化を付けない
- コンテナが挿入するラッパー要素にパディング・マージンを付けない

## 3. 非機能要件

- 新規外部依存を追加しない(既存の GTK4 バインディングの範囲で実装する)
- `go build ./...`、`go test ./...`、gofmt が通ること

## 4. 制約条件

- GUI の見た目の最終確認は手動(自動 E2E なし)

## 5. 成功基準

### 5.1 受け入れ基準
- [ ] ウィンドウ幅 800 で、幅の狭いセクションが同一行に複数並ぶ
- [ ] 幅が足りないセクションは次の行に折り返される
- [ ] セクションの並びは config の記述順(左→右、上→下)
- [ ] config リロード・セクション更新・エラー表示が従来どおり動作する
- [ ] 全ユニットテストがパスする

## 6. 確認事項

### 6.1 確認済み事項
- [x] セル幅: 自然な幅で詰める(homogeneous 格子にはしない)
- [x] 縦一列レイアウトへ戻す設定: 不要(常時 flow に置き換え)
- [x] 間隔: 横 2 unit(12px)/ 行間 0
