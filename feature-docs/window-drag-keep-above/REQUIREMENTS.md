# window-drag-keep-above - 要件定義書

## 1. 概要

### 1.1 背景
初回リリースの実機確認で、ウィンドウのドラッグ移動がセクション表示の上では効かないことが判明した。また常駐ウィジェットとして最前面固定オプションが欲しいという要望が出た。

### 1.2 目的
- ウィンドウ全体（表示テキストの上を含む）どこでも左ドラッグで移動できるようにする
- 最前面固定オプションを追加する（デフォルト有効、右クリックメニューでトグル可能）

### 1.3 スコープ
既存 data-viewer アプリの修正。対象は ui / config / app 層。

## 2. 機能要件

### 2.1 機能一覧
| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F01 | 全面ドラッグ移動 | ラベル・出力テキストの上を含むウィンドウ全体で左ドラッグ = 移動 | 高 |
| F02 | 最前面固定設定 | config `window.keep_above`（デフォルト true）で起動時から最前面固定 | 高 |
| F03 | メニュートグル + 永続化 | 右クリックメニューにチェック付き「最前面に固定」を追加。トグルは即時反映され、config ファイルにも書き戻す | 高 |
| F04 | バックエンド両対応 | X11（XWayland 含む）では EWMH で制御。Wayland ネイティブではアプリから設定不可のため項目を無効化して案内 | 高 |

### 2.2 機能詳細

#### F01: 全面ドラッグ移動
- 左ボタンのドラッグをウィンドウ内のどこで開始しても（セクション名ラベル・出力テキスト・エラーバナー・余白のいずれでも）コンポジタのインタラクティブ移動が始まる
- 右クリックは従来どおりどこでもコンテキストメニューを開く
- クリック（ドラッグ距離ゼロ）は何もしない

#### F02/F03: 最前面固定
- config スキーマに `window.keep_above`（bool、省略時 true）を追加
- 起動時・リロード時に config 値を適用
- メニューのトグルは即時適用し、config ファイルの `keep_above` 値を書き換えて永続化する
  - 書き戻しは対象キーのみ更新し、ファイルの他の内容（コメント含む）を可能な限り保持する
  - 自分の書き込みで発火する watcher リロードは同値適用となり無害であること

#### F04: バックエンド両対応
- X11 バックエンド（`GDK_BACKEND=x11` での XWayland 起動を含む）: EWMH `_NET_WM_STATE_ABOVE` で最前面を制御
- Wayland バックエンド: アプリからの制御は不可（GNOME/Mutter の仕様）。メニュー項目は無効化し、WM 側機能（Alt+Space →「常に手前に表示」）の利用を示すツールチップ/表記とする。config 値は保持のみで適用しない
- どちらのバックエンドでもクラッシュ・エラーを出さない

## 3. 非機能要件
- 判断ロジック（config 書き戻し、状態決定、バックエンド分岐の判定）は GTK 非依存パッケージに置き `go test` でカバーする
- X11 固有処理は独立したファイル/コンポーネントに隔離する

## 4. 制約条件
- GNOME / Mutter は Wayland ネイティブアプリの keep-above 設定手段を提供しない（GTK4 に API なし、layer-shell 非対応）
- 起動バックエンドの選択（Wayland / XWayland）はユーザーの環境変数に委ねる

## 5. 成功基準
- [ ] セクション出力テキストの上から左ドラッグしてウィンドウが動く
- [ ] `GDK_BACKEND=x11` 起動でウィジェットが他ウィンドウより手前に維持される（デフォルト）
- [ ] メニューのトグルで即時に最前面が外れ/戻り、config ファイルに反映される
- [ ] Wayland ネイティブ起動では項目が無効化され、クラッシュしない
- [ ] `go test ./...` / `go build ./...` / `gofmt` が green
