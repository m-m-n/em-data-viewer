# Task Plan: task0001 — config: keep_above field + comment-preserving write-back

## Goal

Add `window.keep_above` (default true) to the config schema with
validation, and deliver `config.UpdateKeepAbove` — an atomic, single-key,
comment-preserving YAML write-back.

## Requirements

FR2, FR3 (write-back half), NFR2

## Scope

### Files to Create
- `internal/config/writeback.go` — `UpdateKeepAbove` per the Shared Components contract
- `internal/config/writeback_test.go`

### Files to Modify
- `internal/config/config.go` — `Window.KeepAbove bool` field
- `internal/config/load.go` — default true when absent; non-boolean → validation error
- `internal/config/load_test.go` — new cases

## Design

- Contracts in IMPLEMENTATION.md Shared Components are binding.
- Default handling: distinguish "absent" from "explicit false" during
  decode (nullable intermediate), materialize as plain `bool` on `Config`.
- `UpdateKeepAbove`: parse the file with the yaml.v3 node API, locate or
  create the `window` mapping and its `keep_above` scalar, set the value,
  re-encode, write to a temp file in the same directory, rename over the
  original. Comments and unrelated keys survive the round trip.
- Failure modes (missing file, unparsable YAML, unwritable dir) return a
  wrapped error and leave the original file untouched.

## Acceptance Criteria (MANDATORY)

- [ ] AC-1: `keep_above` absent → Config value true; explicit `false` → false; explicit `true` → true.
- [ ] AC-2: A non-boolean `keep_above` is a validation error (existing parse-error semantics).
- [ ] AC-3: `UpdateKeepAbove` flips only the key: all other keys AND comments in a fixture file survive byte-comparable except the changed line/value; the key is created under `window:` when absent (including when `window:` itself is absent).
- [ ] AC-4: `UpdateKeepAbove` on a missing/unparsable/unwritable target returns an error and the original file is unchanged.
- [ ] AC-5: The write is atomic (temp + rename, observable by implementation and by no-partial-content on injected failure).
- [ ] AC-6: `go test ./...` passes headlessly; no gotk4 import; `gofmt` clean.

## Test Notes

- Table-driven fixtures with comments (`# ...`) above and beside keys to
  lock comment preservation.
- t.TempDir for write-back tests; read-only dir case for AC-4.

## Out of Scope

- Applying the value to the window (task0002/0003); menu UI.
