# em-data-viewer

Ubuntu / GNOME / Wayland 向けのデスクトップウィジェット。Go と gotk4
(GTK4) で構築されている。YAML 設定ファイルで定義したシェルコマンドを
実行し、その標準出力を装飾のない単一ウィンドウに複数セクションとして
表示する。設定ファイルは監視されており、スタイルやコマンドの変更は
再起動なしに即時反映される。

## 機能

- **ウィジェットの挙動**
  - 設定駆動のセクション: インターバルモード（実行ごとに内容を置き換え）
    とストリームモード（行を追記し `max_lines` で上限）
  - コマンド出力を Pango マークアップとして描画。不正なマークアップは
    プレーンテキストにフォールバック
  - 設定のライブリロード: スタイル・コマンドの変更は再起動なしに反映。
    不正な設定は直前の正常な設定を維持し、エラーバナーを表示
  - ウィンドウ上のどこをドラッグしても移動可能。右クリックでコンテキスト
    メニュー（終了、最前面固定の切り替え）を表示
  - 最前面固定（keep-above）。設定駆動でデフォルト有効
    （X11/XWayland のみ。ネイティブ Wayland では無効化）
  - 起動時のプレゼンテーションを遅延: ウィンドウは一度だけ、既にフィット
    したサイズで表示される（過大サイズでのちらつきなし）

- **レイアウト**
  - コンテンツに追従する動的ウィンドウ高さ。モニタ高さで上限あり
  - 貪欲法による自然幅の行パッキング: セクションは実際の幅で密に詰まり、
    必要に応じて次の行に折り返す
  - 強制改行（config の `type: break`）で任意の位置に行の区切りを挿入
  - 行間・行内セクション間に浮かせた罫線（divider）を表示

- **出力の描画**
  - 出力のデフォルトフォントサイズは 11pt（config で上書き可能）
  - すべての出力経路で末尾の改行を除去（内部の空行は保持）

- **デスクトップ統合**
  - 単一の SVG ソースからビルド時にアイコンを生成。hicolor テーマ
    アイコンと `.desktop` エントリを deb パッケージに同梱
  - アイコンをバイナリに埋め込み（GResource）、deb をインストールせず
    実行した場合にも表示
  - アプリケーション ID を `.desktop` ファイル名と一致させ、Wayland の
    ドックでアイコンを解決可能に

## 設定

設定ファイルの場所: `$XDG_CONFIG_HOME/em-data-viewer/config.yaml`
（フォールバック: `~/.config/em-data-viewer/config.yaml`）。CLI の
位置引数でパスを上書きできる。設定例は `config.yaml.example` を参照。

## ビルド

```sh
make build   # build/ にバイナリをビルド
make test    # go test ./...（ビルド時リソースを先に生成）
make dpkg    # build/ に .deb パッケージを生成
```

ビルドには `rsvg-convert` と `glib-compile-resources` が `PATH` 上に
必要。
